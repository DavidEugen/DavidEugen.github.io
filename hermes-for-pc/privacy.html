개인정보처리방침

시행일: 2026년 9월 27일

HermesForPc는 개인 학습 목적으로 사용하는 Google Workspace CLI 앱입니다.

1. 접근 권한

HermesForPc는 사용자가 Google OAuth 동의 화면에서 명시적으로 승인한 범위의 Google Workspace 데이터에만 접근합니다. 승인하지 않은 데이터나 서비스에는 접근하지 않습니다.

2. 데이터의 이용 및 보관

접근한 데이터와 인증 관련 정보는 앱의 기능 제공 및 개인 학습 목적에만 사용합니다. 데이터는 사용자의 로컬 컴퓨터에만 저장되며, 운영자가 별도로 수집하거나 원격 서버에 저장하지 않습니다.

3. 제3자 제공

HermesForPc는 사용자의 Google 사용자 데이터 또는 개인정보를 제3자에게 판매, 대여, 공유 또는 제공하지 않습니다.

4. Google API 서비스 사용자 데이터 정책

HermesForPc는 Google API Services User Data Policy를 준수하며, 제한된 사용 요건을 포함한 적용 가능한 정책을 따릅니다.
